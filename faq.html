Official how-to. This chat cannot see your house. Login code is never written here — it is in the host’s note or PDF. Person: info@houss.co.in · Short guide

Install and sign in

How do I install on Android?

Chrome → Become a tester → install from Play Store. Uses the Google account already on the phone.

How do I install on iPhone?

Install TestFlight → open the Houss TestFlight link in Safari → Accept → Install.

I did not get an SMS / what is the OTP?

This trial does not send SMS. Type the code from the host’s note or PDF. This page will never print that code. Resend will not send a real SMS.

Do you need my Gmail or Apple ID?

No. Store install uses the account on the phone. Houss login is the Indian mobile number.

Home and people

Who creates the household?

One owner only. Name the family and the house, tap Create household. Staff must not create another home.

I see an empty home

The owner should add your mobile under Manage → Family Members or Staff Management. Sign in again with that number.

How do I add staff / family / a child?

Manage → Staff Management (name, mobile, role) · Family Members (name, mobile) · Children (mobile, optional DOB, permission ticks). They sign in with that number.

Staff works in two houses

Each owner adds the same mobile. Staff switch house on Home or Profile. Houses never mix data.

Owner vs staff screens

Owners: Home, Daily, Calendar, Manage, Profile. Staff: Home and Profile only, large job + attendance tiles first. An Activity tab is not shown in this version.

Daily work

Meals

Home → Request a meal or Meals. Owner/cook can set today’s dish. Cook accepts, prepares, marks done. Optional photos.

Driver

Home → Book a driver. Place, time, which driver, today or up to 90 days. India time. Driver accepts / starts / completes. This is not Vehicles.

Where is a driver’s licence?

Not Vehicles (RC, insurance, PUC). Driver: Profile → My documents → Driving licence. Owner: Manage → Staff Documents.

Shopping

Add a line, optional photo. Staff mark purchased with amount + receipt. Owners mark done. Spending tab shows rupees. Changing a line after send is limited in the current store app.

Clothes

Clothes / कपड़े: press, dry clean, or dhobi. Pile by person or House. Confirm return counts.

Voice

Home → Voice. Speak or type Hindi/English, edit draft, Submit. Meals, named driver, shopping, clothes, duties. Not vehicles or appliances.

Attendance

Household Settings: Self (about 50 m from home pin), Guard, or Owner only. Save My location at the gate first for Self.

Payroll

Home or Manage → Payroll. Wage, calendar, advances, Pay salary. Staff see only their own.

Duties

Owners create lists. Staff tick Home → Duties.

Calendar

Family Calendar. Notify chosen staff. Optional meal or driver on the event. Reminders off unless you pick a time. Staff see only shared events.

Gate

Guard photographs a parcel. Owner approves or rejects.

Vehicles and appliances

Manage or Home tiles. Papers as photo or PDF. Expiring soon on owner Home. Shop phone on an appliance bill can be tapped to call.

My documents vs Staff Documents

Staff: Profile → My documents (Aadhaar, PAN, licence…). Owner: Manage → Staff Documents. Lock keeps a home copy.

Settings and account

Language and appearance

Profile → Language. Profile → Appearance (light / dark / system; owners grid or list).

Notifications

Profile → Push notifications. Job reminders only if a time was picked on that job.

Delete my account

Profile → Account & privacy. Three confirms, then logout. Removed within 60 days. Sole owner must add another owner first. Also legal.houss.co.in/account-deletion.html.

Plans

This trial has every feature on; no payment in the app yet. Listed: Free ₹0, Plus ₹399/month, Multi ₹699/month. Manage → Subscription & Plans.

What this bot cannot do

It cannot see your house or type your login code. Email info@houss.co.in with Android or iPhone and the mobile number.
